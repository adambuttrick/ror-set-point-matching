Does this affiliation string say the author is affiliated with the institution shown? Answer yes if the string names the institution (by any of its names, other names, acronyms, former names or obvious typos) or a unit that is part of it (campus, school, college, department, institute, lab, center, hospital). Answer no if the string names only a different organization (including one with a similar name or the same acronym elsewhere), only a place, only a person, or no organization at all. Several organizations may be listed; answer yes if any of them is this institution or a unit of it. A unit name counts only when the string does not present it as belonging to a different organization, and an acronym counts only when the string does not spell it out as, or attach it to, a different organization. An organization merely located on the institution's campus, or a fellowship, prize or degree named after it, is not an affiliation.
